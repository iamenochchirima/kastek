# Coding standards

This file is for project-specific review rules that require human judgment. It is not a duplicate
of [`AGENTS.md`](AGENTS.md), the language formatters, linters, or CI checks.

No additional project-specific judgment rules have been recorded here yet. The repo's existing
working and UI rules remain in `AGENTS.md`.

When a mistake repeats, add a rule here only if a reviewer must make a judgment that a reliable
automated check cannot make. Put mechanically checkable rules in a test, lint rule, or CI check.
Record the observed failure and where the rule applies. Do not add speculative rules.
