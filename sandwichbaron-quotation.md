## Website Agent for Sandwich Baron

This quotation is for the development and setup of a **website AI agent** for Sandwich Baron.

The website agent will be built to help website visitors quickly get answers about Sandwich Baron products, stores, contact details, and general ordering guidance.

## Included Functionality

The website agent will be configured to:

- Answer frequently asked questions from website visitors
- Help users find menu categories and selected menu items
- Provide menu price guidance from the approved knowledge base
- Share safe reference links for menu browsing and ordering
- Help users find Sandwich Baron store locations
- Share contact details where relevant
- Assist with catering-related enquiries
- Route franchise-related questions to the correct contact path
- Hand off uncertain, sensitive, or unresolved questions to a human contact path

## Knowledge Base Scope

The website agent will be trained on:

- Official Sandwich Baron website content
- Approved menu and pricing snapshot
- Store information confirmed in the current knowledge base
- Contact and franchising information
- Catering and platter guidance

## Important Notes

- Menu prices will be treated as a guided static snapshot and can be refreshed when needed
- Final order totals remain subject to confirmation at checkout or by the relevant store
- This quotation covers a website agent only
- This quotation does not include WhatsApp automation, voice agent functionality, or live system integrations
