# Landing v2 artwork

The owner approved the blue/Geist business-first laptop and personal-device composition
on 29 October 2026. Artwork was generated with the built-in image generation tool and
encoded locally to WebP, retaining transparency in device images. These are fictional
product illustrations, not screenshots of a real customer or proof of personal execution.

| Asset | Size | Generation brief |
| --- | --- | --- |
| `business-laptop.webp` | 1600 × 910 | Isolated silver laptop with the approved Riverside Studio customer-service screen, Maya's consultation conversation, booking confirmation, knowledge and calendar indicators. Transparent background, thin bezel, soft blue reflections, readable Geist-style UI. |
| `business-laptop-small.webp` | 800 × 455 | Smaller encoding of the same artwork. |
| `personal-devices.webp` | 1600 × 910 | Isolated laptop, tablet and phone showing the same Ari agent and client brief with responsive screen layouts. Transparent background, realistic silver hardware, soft studio shadows and blue reflections. |
| `personal-devices-small.webp` | 800 × 455 | Smaller encoding of the same artwork. |
| `studio.webp` | 900 × 600 | Fictional creative studio interior with walnut table, beige walls, tall windows, linen curtains and warm daylight. No people, text, logos or embedded interface. |

The device generation used the approved full-page design as a composition reference;
the briefs requested no surrounding page, hardware logos, metrics, sparkle icons or
additional scenes. The studio image uses an original generation brief. The backgrounds'
light effects are CSS, not generated video. Knowledge, handoff, settings and embedded
widget examples are HTML; channel logos reuse `../integrations/BRAND-ASSETS.md`.

The previous coastal images are removed because this route no longer uses them.
