# Agents interface concepts

Visual references for the Agents dashboard redesign. The concepts use Geist-style typography, concise labels, fine outline icons, compact tables, and neutral light and dark themes. The dark theme uses charcoal surfaces rather than purple.

- [Customers list, light](customers-list-light.png)
- [Customer detail, dark](customer-detail-dark.png)
- [Agent chat, dark](agent-chat-dark.png)
- Agent configuration: [light](agent-configuration-light.png), [dark](agent-configuration-dark.png)
- Connections: [light](connections-light.png), [dark](connections-dark.png)
- Agent tools and MCP connection: [light](agent-tools-mcp-light.png), [dark](agent-tools-mcp-dark.png)
- [Skills and website, light](skills-website-light.png)

These are visual concepts, not a statement of implemented integrations or available features. Provider names, connection states, sample people, and controls are illustrative. In the skills concept, Gmail and WhatsApp are shown incorrectly as skills. They belong under tools or channels; skills are reusable instructions and capabilities. Preserve that distinction when implementing.
