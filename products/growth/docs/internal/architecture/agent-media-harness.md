# Agent media boundaries

Growth owns its ContentMediaAsset records and ordinary publishing/Inbox media operations.
An embedded execution task receives only product-authorized context and results through the
current typed Growth action API. A media ID or provider URL in model text is not access authority.

The old AgentResponse@1, installation media handlers and Growth customer-widget previews are
removed. Growth's text assistant does not silently expose personal uploads or customer attachments.

Standalone Agents owns its own artifact and customer-channel adapters. Current support is
recorded in its [source boundary](../../../../agents/docs/source-boundary.md).
