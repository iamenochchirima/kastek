# Architecture decision records

Record a product-level architecture decision here only when it is hard to reverse, surprising
without its context, and the result of a real trade-off. Use numbered files such as
`0001-short-name.md`. Each record needs the context, decision, and reason.

There are no root-level product ADRs in this directory yet. Do not create a placeholder decision.
Agent Platform ADRs under `agents/docs/adr/` remain in place and are not being moved by this setup.
