# Deferred plans

These plans are retained for reference but are not part of the current implementation focus.
Their status fields describe the recorded state at deferral, not active work. They are not marked
complete. When work resumes, confirm the current requirements in an issue and link the retained
plan. Do not move it back into `docs/plans/active/`.

Current Agents direction and implementation planning are maintained in the Kasitek Agents Stash
project.
