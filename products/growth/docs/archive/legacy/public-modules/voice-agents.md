# Voice Agents

The Voice Agents module is exposed in the tenant portal for automation and support-focused roles.

## Current portal workflow

The current UI supports:

- creating a voice agent
- setting its name
- defining use case
- entering a greeting script
- viewing deployed agents
- viewing a call log

The current agent cards are built around:

- phone number
- status
- calls handled
- average call duration
- satisfaction score

## Current implementation status

This module is currently **UI-present with placeholder data**.

The temporary tenant API client still serves placeholders for:

- voice agent lists
- voice agent creation
- voice call logs

The workflow direction is visible, but this module is not yet backed by a dedicated tenant runtime implementation.
