# Nurturing

The Nurturing module is already present in the tenant portal and designed around lead follow-up sequences.

## Current portal workflow

The current UI supports:

- creating a sequence
- choosing a channel
- setting a trigger event
- listing sequences
- viewing summary stats

Supported channels currently include:

- email
- WhatsApp
- both

Supported triggers currently include:

- new lead captured
- tag added
- form submitted
- manual enrollment

## Current implementation status

This module is currently **UI-present with placeholder data**.

The temporary API client still returns placeholder responses for:

- sequence lists
- nurturing stats
- sequence creation

The workflow and data model direction are already visible in the product, but this module is not yet running on a dedicated tenant backend service.
