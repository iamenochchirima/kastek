# Client Reporting

The Reporting module is exposed in the tenant portal and gated by reporting roles.

## Current portal intent

The reporting area is positioned around:

- client-facing dashboard views
- reporting metrics
- branded reporting delivery

## Current implementation status

This module is currently **not yet backed by dedicated tenant backend reporting endpoints** beyond the tenant dashboard and other existing operational summaries.

The temporary portal API layer still returns placeholder data for reporting-specific dashboard lists and metrics.

## Current guidance

Treat the Reporting screen as a staged module:

- visible in the product
- aligned with the intended reporting model
- not yet the source of record for tenant analytics workflows
