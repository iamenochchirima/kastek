# Reputation

The Reputation module is the tenant-facing review automation and negative-intercept area.

## Current portal workflow

The current UI supports:

- creating review campaigns
- choosing delivery channel
- storing a positive redirect URL
- enabling negative intercept behavior
- viewing campaign-level performance cards
- viewing aggregate reputation statistics

Supported channels currently include:

- email
- WhatsApp
- SMS

## Current implementation status

This module is currently **UI-present with placeholder data**.

The temporary API layer still returns placeholders for:

- review campaign lists
- campaign creation
- review stats

So the product language and workflow are already established, but this is not yet a fully backed production workflow in the tenant backend.
