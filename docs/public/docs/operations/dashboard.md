# Dashboard

The dashboard is one of the fully backend-backed areas in the current tenant platform.

## What the dashboard shows today

The live summary cards currently pull from the tenant backend and show:

- total clients
- active agents
- total conversations
- requests this month

## Recent activity

The current activity feed is assembled from live workspace data, including:

- client creation events
- client invite events
- lead creation events
- conversation updates
- agent updates

## Service status block

The `Services` panel currently reflects whether key categories have any active data in the workspace:

- Workspace Access
- Client Management
- Automation Agents
- Conversation Hub
- Lead Pipeline

This is not a marketing card. It is driven from current tenant workspace counts.
