# Analytics plans and research

This directory contains analytics product, metric, and architecture exploration that is not
currently being implemented.

Keep implementation plans and checklists under `docs/plans/active/` once execution is approved and
underway. Move finished implementation records to `docs/plans/completed/analytics/` when the work
is complete.

These documents are planning inputs, not current product behavior or authorization to change the
analytics registry, database schema, APIs, or user interface.
