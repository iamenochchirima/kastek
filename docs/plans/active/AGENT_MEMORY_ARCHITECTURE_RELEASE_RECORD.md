# Agent memory architecture pre-release record

This is a pre-release verification record for the memory architecture upgrade. It is not a
production release approval. The source tree is still an uncommitted implementation worktree, so
the deployment artifact and platform release tag must be assigned before staging.

The reproducible local manifest is generated with `pnpm --dir agents release:memory:manifest` and
checked with `MEMORY_RELEASE_ALLOW_DIRTY=true pnpm --dir agents release:memory:verify` during local
pre-release work. A staging candidate must pass the verifier without `MEMORY_RELEASE_ALLOW_DIRTY`.
The manifest records the base commit, a worktree fingerprint, migration range, rollout flags,
analytics registry checksum, and content digests for the built Agents and MCP artifacts without
including secrets.
