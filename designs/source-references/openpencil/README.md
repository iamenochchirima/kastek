# KasiTek Labs landing design

Created 10 October 2026 directly in OpenPencil through MCP. This is an editable design draft for the Labs landing page.

Open `kasitek-labs-landing.fig` in OpenPencil. The canvas contains a 1440px desktop page, a 390px mobile page and an identity board. Text, vectors and interface previews are editable layers.

The Ink & Signal direction uses Inter, warm paper, near-black and vermilion. A geometric K anchors the wordmark and hero. Agents has a dark section, Growth a sage section and Agency a pale blue section. Custom software work has a separate Studio section.

The chosen headline is "Good ideas. Real working tools." Two alternatives appear on the identity board. Preview interfaces and customer names are illustrative design content, not screenshots or customer endorsements. Product capabilities and destination links should be checked when implementing the page.

PNG files provide review previews. JSX files are OpenPencil's canonical editable render format, exported from the finished nodes. They are not React website components.

Validation: desktop, mobile and identity exports were visually inspected. All Inter faces are available without substitution. The final text overflow and major sibling-overlap check passed. The live website has not been changed by this design pass.
