# Parloa palette reference

Saved from the screenshot supplied by Enoch. `source.png` preserves the original reference. The hex values were sampled from the centre of each swatch, in left-to-right order. These are screenshot samples, not official Parloa brand specifications.

Open http://localhost:3010/references/parloa-palette/ to view the swatches. `palette.json` stores the values, and `../../shared/parloa-palette.css` provides optional CSS variables.

For the next Labs colour pass, consider ivory for page backgrounds, deep brown for primary text, orange or vermilion for primary actions, and muted slate for small interface accents. The saved green product previews and services section remain part of the current direction. Check text contrast for each actual foreground/background pairing before applying a colour.

The palette has not been applied to the landing page.
